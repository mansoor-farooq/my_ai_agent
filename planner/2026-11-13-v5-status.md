## Current V5 work

- V5.0 managed MCP lane: implemented; local package and focused release suite
  verified on 2026-11-13.
- `prepare_managed_action` creates a short-lived canonical manifest;
  `run_managed_task` recomputes project/base revision, scope, action hashes,
  check commands, policy and expiry before executing. Protected paths and
  symlink/path guards remain enforced in the managed executor.
- A local HMAC key and receipt persist under the ignored project run directory.
  The append-only hash-chained ledger records run, approval and effect states.
  Changed bytes under a replayed key, corrupt history, expired receipt, policy
  drift or unknown filesystem state blocks.
- Recovery tests cover interruption before a write and after the file effect
  but before completion is recorded. Promotion of the exact reviewed patch is
  locked and replay-safe.
- Speed policy: on-demand skills, relevant repository-map symbols and verified
  project memory; one primary specialist and narrow checks for routine tasks.
  Premium research/security/migration work keeps independent review. No speed
  or accuracy percentage is claimed without measured benchmark observations.
