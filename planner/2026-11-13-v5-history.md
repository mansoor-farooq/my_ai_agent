# Ultra Agent V5 Roadmap Changelog

## 2026-11-13 — Initial roadmap and status ledger

- Recorded V4.4 / package `1.13.0` as the inspected repository baseline.
- Added V5.0 trust-boundary, V5.1 execution-containment, V5.2 quality-proof,
  and V5.3 portability milestones.
- Separated source presence from test, CI, host, install and sandbox verification.
- Carried forward the Antigravity hook failure limitation as an open V5 control
  requirement; no claim of a fully fail-closed native editor boundary was made.
- No implementation, tests, build, install or push performed for this roadmap
  update.

## 2026-11-13 — V5.0 manifest and managed approval slice

- Added canonical action manifests, exact manifest recomputation, an MCP
  `prepare_managed_action` step and a process-local one-use HMAC receipt.
- Made the manifest mandatory for the managed runtime and reject mismatched
  writes/commands/policy before managed side effects.
- Bundled the module in the portable plugin source list and updated architecture
  notes to distinguish host review, local receipt and OS sandbox claims.
- Focused tests passed: 28 total across V5 manifest/MCP, V4 runtime/MCP and
  Antigravity pre-tool guard suites. A temporary signed plugin staging build
  confirmed the module checksum and MCP tool config, then the staging folder
  was removed. No release ZIP build, install, push or hosted CI run.
- V5.0 remains partial: approval provenance is not host-signed identity,
  Antigravity hook errors may fail open, and durable effect/approval lifecycle
  reconciliation remains to be implemented.

## 2026-11-13 — V5.0 durable managed lane and signed package

- Replaced process-local approval state with a local file-backed receipt
  authority and hash-chained append-only ledger for run, approval and effect
  transitions. Exact replay resumes; corrupt state, changed bytes, policy drift,
  expiry and uncertain filesystem state stop safely.
- Added crash-reconciliation at the write boundary, replay-safe patch promotion,
  mandatory verification checks, and manager fast-path guidance for on-demand
  skills, repo maps and targeted checks.
- Built package `1.14.0`: Antigravity strict validation passed; Doctor passed
  20/20; focused suite passed 187 tests with 0 failures and 6 intentionally
  skipped PostgreSQL RAG integration checks because the DB gate was not enabled.
- Owner-signed ZIP SHA256:
  `55F40872BAE592FB78A6668BD1442A54551B70727EE20E490513FACB1D3B92DD`.
- Fixed auto-update discovery to include global agent profile roots. Build
  detected those profiles and planned 573 refreshes, but the running Antigravity
  process held the plugin directory open; install stopped before profile sync.
  Active-host update, hosted CI, Git push, OS containment and host-signed human
  approval remain unverified/open.
