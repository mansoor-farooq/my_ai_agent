# Premium UI/UX prototyping

Map user intent, information architecture, states, task success, and responsive behavior before adding visual spectacle. Build a small representative flow with real-ish content, loading/empty/error states, keyboard and touch paths, reduced-motion behavior, and a clear handoff contract.

Use motion, depth, Three.js, or shader effects only when they improve comprehension or brand expression; provide a progressive fallback for unsupported devices and keep interaction latency measurable.

Stop when the prototype demonstrates the critical path, non-happy paths, accessibility behavior, and responsive composition—not merely a static hero screenshot.
