# Mansoor Research Synthesis
Start with repository evidence, then bounded external research. Prefer primary sources and maintained open-source projects. Keep a source ledger with URL, date/revision, claim, confidence, license and unresolved conflicts. Return options, trade-offs and a recommendation without pretending that a search result is implementation proof.

Stop condition: the decision is source-backed or the remaining uncertainty is explicitly handed to the owner.
