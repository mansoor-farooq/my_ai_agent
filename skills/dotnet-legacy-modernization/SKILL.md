# .NET Legacy Modernization

Map runtime dependencies, Windows-only APIs, hosting, authentication, data contracts and critical workflows before migration. Establish characterization tests and a deployable sequence. Use adapters/strangler boundaries where useful. Separate compatibility changes from product changes; prove behavior and rollback at each milestone. Avoid promising a one-step rewrite without inventory evidence.
