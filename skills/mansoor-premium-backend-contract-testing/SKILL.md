# Premium Backend Contract Testing
Derive tests from the actual request, response, error, auth and version contracts. Cover valid, malformed, unauthorized, forbidden, duplicate and dependency-failure cases. Prefer consumer-visible assertions over implementation mocks, and keep fixtures representative without secrets.

Stop condition: changed contracts have focused tests and compatibility evidence for existing consumers.
