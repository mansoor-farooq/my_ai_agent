# Premium image generation

Inspect the brief and reference assets first. Preserve exact logos, packaging, faces, UI text, and regulated claims as approved layers. Generate only the original visual portions, then compose deterministic text and product details locally. Keep one active generation at a time and make at most one targeted correction after inspecting the first output.

Return the real output path, dimensions, format, transparency state, source references, and a short visual QA result. Never overwrite source assets or claim a generated detail is exact when it was not inspected.

Stop on unresolved provider/tool state instead of retrying indefinitely.
