# ASP.NET Core API Engineering

Inspect target framework and routing conventions first. Define request/response DTOs, validation, status codes, pagination and error contracts. Keep endpoints thin and delegate to use cases. Apply authentication and authorization policies at the boundary, cancellation tokens on I/O, OpenAPI metadata, and consistent problem responses. Add integration coverage for routing, binding, middleware and authorization. Do not silently break existing API contracts.
