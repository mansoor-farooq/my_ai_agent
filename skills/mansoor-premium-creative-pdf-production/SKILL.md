# Premium PDF production

Choose page size, bleed, margins, color profile, image resolution, font embedding, metadata, navigation, and accessibility targets before export. Generate from structured source where possible so the PDF is reproducible, then render representative pages to images and inspect the actual output.

Check clipping, widows/orphans, links, bookmarks, selectable text, contrast, file size, and print-safe imagery. Keep source files unchanged and report the exact output path and export settings.

Stop when rendered-page QA and machine-readable checks agree; do not call a PDF complete from source inspection alone.
