# Mansoor Media Render QA
Keep source media immutable and work from proxies when useful. Validate timing, captions, audio peaks, frame size, aspect ratio, color, codecs, playback and final output location. Inspect the rendered artifact, not only the timeline or command log. Preserve licensed/source asset references.

Stop condition: the requested export plays or opens correctly and visual/audio checks are recorded.
