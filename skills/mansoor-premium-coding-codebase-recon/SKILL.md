# Premium coding reconnaissance

Inspect the relevant files, package scripts, tests, runtime entry points, and adjacent implementations before editing. Trace the actual call path and identify contracts, invariants, generated files, and protected boundaries. Prefer existing patterns over inventing a parallel architecture.

Stop when the change scope, risks, and verification commands are explicit.
