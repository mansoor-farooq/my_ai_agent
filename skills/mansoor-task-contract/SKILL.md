# Mansoor Task Contract
Translate the parent assignment into objective, owned paths, non-goals, acceptance checks and a stop condition before editing. Preserve the parent manager as integrator. If ownership is missing or overlaps another worker, return a blocker instead of guessing. Keep the contract small enough to review and include the exact verification command that can prove completion.

Stop condition: no source edit starts until objective, ownership and acceptance are explicit.
