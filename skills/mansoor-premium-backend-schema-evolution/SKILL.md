# Premium Backend Schema Evolution
Inspect consumers, writers, migrations, serializers, reports and rollback constraints before changing a shape. Prefer expand–migrate–contract compatibility, version external payloads and preserve historical meaning. Do not silently rename or reinterpret production data.

Stop condition: forward compatibility, migration order, rollback and affected consumers are evidenced.
