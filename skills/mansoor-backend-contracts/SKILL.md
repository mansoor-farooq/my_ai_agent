# Mansoor Backend Contracts
Trace request-to-data flow, authorization, validation, errors, transactions, retries and observability before editing. Preserve existing API/database contracts unless the work item explicitly changes them. Add negative-path checks for auth, invalid input, duplicate/retry and downstream failure.

Stop condition: contract compatibility and failure behavior are verified at the changed boundary.
