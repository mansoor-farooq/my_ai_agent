# Mansoor Accessibility and Visual Regression
Treat motion and visual polish as progressive enhancement. Verify semantics, focus order, keyboard operation, contrast, reduced motion, zoom and screen-reader states. Capture deterministic screenshots at agreed viewports and compare meaningful deltas, not anti-aliased noise; pair every visual pass with functional checks.

Stop condition: accessibility and visual baselines pass, or each variance has an owner-approved explanation.
