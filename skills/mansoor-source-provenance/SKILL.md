# Mansoor Source Provenance
Record canonical URL, owner, revision/commit, license, source references, security notes, local changes and attribution obligations. Use Open-Source-First decisions: reuse, adapt, inspire or custom. Popularity never replaces license or compatibility evidence; do not copy code or assets without scope proof.

Stop condition: provenance and local adaptation boundary are written beside the change or the source is rejected.
