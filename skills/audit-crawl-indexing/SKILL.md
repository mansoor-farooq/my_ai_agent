# Crawl and indexing audit
Check robots.txt, XML sitemaps, canonical links, redirect chains, status codes, pagination and discoverable internal links. Compare served HTML and rendered DOM where available. Record URL, response evidence, expected behavior, severity and affected template.

Stop condition: the requested route/sample matrix is covered or the authorized provider is blocked.
