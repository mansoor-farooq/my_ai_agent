# Premium export preflight

Build an explicit output matrix: filename, dimensions, format, color mode/profile, resolution, transparency, compression, metadata, destination, and acceptance threshold. Run deterministic checks for dimensions, file readability, embedded resources, font handling, links, and naming.

Inspect a representative rasterized or rendered preview for every materially different layout. Keep intermediate files separate from final deliverables and report skipped checks rather than implying they passed.

Stop on any mismatch in the output matrix or unreadable artifact.
