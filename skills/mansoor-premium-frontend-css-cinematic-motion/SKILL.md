# Mansoor CSS Cinematic Motion
Animate compositor-friendly properties first (`transform`, `opacity`, `clip-path` where supported). Centralize timing/easing tokens, avoid layout thrash and respect `prefers-reduced-motion`. Use layered depth to clarify hierarchy, never to hide content or create unreadable contrast.

Stop condition: motion has a reduced-motion mode, no obvious layout shift and a measured interaction path.
