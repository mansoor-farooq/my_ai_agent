# Premium system mapping

Start read-only. Inventory entry points, deployables, package boundaries, runtime dependencies, data stores, external integrations, background jobs, permissions, and critical user journeys. Trace real call paths and mark inferred edges separately from observed edges.

Return a compact context map with owners, invariants, hotspots, unknowns, and a proposed investigation order. Do not redesign before the existing system is legible.

Stop when the map is sufficient to explain the requested change and every major uncertainty has a bounded verification path.
