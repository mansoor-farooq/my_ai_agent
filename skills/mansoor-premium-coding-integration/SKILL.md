# Premium integration coding

Trace the external contract, timeout, retry, idempotency, version, failure, and rollback behavior before implementation. Keep adapters narrow and test them with realistic contract fixtures or safe local doubles.

Stop when success, timeout, malformed response, duplicate delivery, and unavailable dependency paths are covered.
