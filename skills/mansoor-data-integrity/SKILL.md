# Mansoor Data Integrity
Identify identity, ownership, versioning, uniqueness, ordering, retention and rollback invariants. Separate source truth from cache and derived views. Test malformed, stale, duplicate, partial and cross-project data. Never repair historical data silently; produce a bounded migration or owner decision.

Stop condition: invariants and recovery behavior are evidenced or the data change is blocked.
