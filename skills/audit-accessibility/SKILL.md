# Accessibility audit
Combine automated checks with keyboard and rendered inspection. Cover names/roles/value, focus order, keyboard traps, contrast, target size, labels, errors, zoom/text scale and reduced motion. Treat automated results as findings requiring human interpretation.

Stop condition: required routes and viewport/accessibility settings have evidence or a documented gap.
