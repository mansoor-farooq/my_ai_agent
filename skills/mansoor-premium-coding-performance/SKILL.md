# Premium coding performance

Measure a baseline, identify the dominant cost, and change one bottleneck at a time. Preserve correctness, cancellation, backpressure, cache invalidation, and observability. Report measured before/after values and workload assumptions.

Stop when the budget is met or the remaining gap is explicitly documented.
