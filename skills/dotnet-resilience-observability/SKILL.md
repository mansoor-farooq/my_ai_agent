# .NET Resilience & Observability

Instrument request and dependency boundaries with structured logs, metrics and distributed traces. Distinguish liveness from readiness. Set timeouts and cancellation. Retry only transient, idempotent operations with bounded backoff; use circuit breakers/bulkheads where justified. Never log secrets or high-cardinality identifiers as metric labels.
