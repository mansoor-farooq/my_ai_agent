# Premium catalog composition

Treat product data as the source of truth. Define SKU, title, price, unit, availability, image, badge, variant, and legal-copy contracts before layout. Use deterministic templates for repeated cards and reserve art direction for covers, section breaks, and hero compositions.

Handle missing images, long names, currency formats, discount states, pagination, QR/link targets, and localization. Produce a data-to-page manifest so every rendered item can be traced back to its source record.

Stop when counts, prices, images, ordering, and page references reconcile with the source data and rendered pages pass visual QA.
