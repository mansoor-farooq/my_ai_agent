# .NET Upgrade & Dependency Health

Inventory SDKs, target frameworks, package graph and breaking-change exposure. Consult official release notes and migration guides. Upgrade in small coherent groups, inspect transitive changes and lock-file policy, then build/test all target frameworks. Avoid mass-upgrading unrelated dependencies. Record unsupported packages and replacement options.
