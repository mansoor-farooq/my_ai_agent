# Local fallback policy

Make backend, data handling, cost, latency, and quality changes visible. Allow fallback only when the selected backend is ready and the task policy permits it; checkpoint before switching and never silently downgrade evidence requirements.

Stop with a clear result when no backend meets the policy instead of cycling providers.
