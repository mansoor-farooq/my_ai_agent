# Premium secure coding

Validate at trust boundaries, authorize server-side, scope every lookup, protect secrets, and fail closed. Check injection, confused-deputy, ownership, replay, logging, and error-disclosure paths with negative tests.

Stop when security-sensitive behavior has an executable check and no credential or private data is added to logs or artifacts.
