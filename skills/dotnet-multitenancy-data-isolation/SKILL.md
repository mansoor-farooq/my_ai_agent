# .NET Multi-Tenant Isolation

Resolve tenant context only from authenticated, validated sources. Apply tenant filters at every read/write boundary; do not rely on UI filtering. Define behavior for background jobs, admin operations, caches, exports and database constraints. Cover two-tenant isolation, missing tenant, forged tenant input and privileged workflows. Audit intentional global queries.
