# .NET Performance Profiling

Measure a representative workload first. Capture CPU, allocation, GC, database and network evidence. Optimize the dominant cost, not guessed code. Check async blocking, repeated allocations, serialization, N+1 queries and cache behavior. Compare before/after under the same workload and preserve correctness. Avoid premature pooling or caching without invalidation and memory bounds.
