# .NET Database Migrations

Review current schema and migration history before editing. Make migrations forward-safe: expand, deploy compatible code, backfill, then contract in a later release when needed. Preserve data; inspect generated migration SQL; include constraints and indexes based on query patterns. Follow the project's release process for production migrations. Test fresh database creation and upgrade from a representative prior schema.
