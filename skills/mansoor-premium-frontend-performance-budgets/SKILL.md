# Mansoor Frontend Performance Budgets
Set budgets before adding effects: JS/CSS, images/models, LCP/INP/CLS, frame time, GPU memory and network requests. Measure the baseline and the same route after each effect. Lazy-load noncritical scenes, pause offscreen work and provide a lightweight path.

Stop condition: the premium effect fits its measured budgets or is disabled behind an explicit capability decision.
