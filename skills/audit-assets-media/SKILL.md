# Asset and media audit
Inventory representative assets, dimensions, formats, transfer sizes, loading priority, responsive variants, alt text and layout reservation. Recommend the smallest shared-template or pipeline fix and preserve visual intent.

Stop condition: sampled asset classes have measurements and a prioritized remediation list.
