# .NET Caching

Define cache key scope, source of truth, TTL, invalidation and stale-data tolerance before coding. Include tenant/user dimensions where data is scoped. Use bounded memory and stampede protection for hot keys. Do not cache authorization decisions or sensitive data without explicit controls. Cover expiration, invalidation, concurrent misses and outage behavior.
