# Premium debugging

Reproduce the failure, isolate the smallest causal boundary, inspect evidence, and state a falsifiable hypothesis. Fix the cause rather than masking the symptom, then add a regression check that would fail under the original defect.

Stop after one targeted repair and verification; escalate repeated or environment-owned failures instead of guessing.
