# Premium coding release

Run the smallest sufficient verification matrix, summarize changed paths and behavior, record skipped checks and environment limits, and prepare rollback/feature-flag notes. Keep generated artifacts and secrets out of the patch.

Stop only when the owner receives a reproducible result, exact test evidence, and any remaining risk.
