# .NET Packaging & Deployment

Inspect target framework, runtime identifier, hosting model and CI before changing deployment. Use multi-stage containers, non-root runtime users where supported, minimal runtime images, health probes and external configuration. Keep secrets out of image layers. Verify published artifacts, startup, migrations and graceful shutdown in a deployment-like environment.
