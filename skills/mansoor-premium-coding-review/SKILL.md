# Premium code review

Review the diff and changed behavior read-only. Prioritize blocking defects, missing tests, contract breaks, unsafe assumptions, and unnecessary complexity. Check the implementation against the approved plan and actual repository conventions.

Stop with an evidence-backed finding list and explicit verification gaps.
