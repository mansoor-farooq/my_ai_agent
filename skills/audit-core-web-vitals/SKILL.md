# Core Web Vitals and trace audit
Separate lab metrics from field data. Use a performance trace or browser metrics to connect LCP/INP/CLS to request, script, layout and image evidence. Report median/repeat conditions and avoid promising ranking gains from a score.

Stop condition: each reported metric has collection conditions and a likely bottleneck, or remains explicitly unverified.
