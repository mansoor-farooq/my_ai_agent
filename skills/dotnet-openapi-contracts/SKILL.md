# .NET OpenAPI Contracts

Treat OpenAPI as a client-facing contract. Include operation IDs, schemas, auth requirements, error responses and examples. Check generated output for nullable/type accuracy. Detect breaking changes before release and version deliberately. Do not expose internal entities or undocumented implementation details in public schemas.
