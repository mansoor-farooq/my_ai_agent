# Premium test-first coding

Choose the smallest meaningful failing test that expresses the requested behavior, then implement the narrowest change that makes it pass. Cover the nearest negative, boundary, and regression cases without testing implementation details unnecessarily.

Stop when the focused test passes and the relevant broader suite has a recorded result.
