# Local retrieval grounding

Retrieve only project-scoped, current, provenance-tagged evidence relevant to the task. Prefer exact symbols and contracts over broad file dumps. Separate observed source, approved external reference, inference, and unresolved uncertainty.

Stop when every material recommendation has a traceable evidence item or is explicitly marked unknown.
