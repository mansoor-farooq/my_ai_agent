# Secure .NET Coding

Use parameterized database APIs, allowlist validation at trust boundaries, safe output encoding and framework cryptography. Avoid unsafe deserialization, dynamic SQL, path traversal, overbroad exception details and logging secrets. Validate file paths after canonicalization. Keep dependency and runtime versions supported. Report threat, exploit path, impact and smallest fix.
