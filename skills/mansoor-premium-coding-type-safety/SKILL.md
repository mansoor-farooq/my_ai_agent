# Premium type safety

Validate at boundaries, model invalid states explicitly, preserve nullability and units, and keep transport types separate from domain types. Prefer compiler-enforced contracts over comments and unchecked casts.

Stop when typecheck, schema validation, and representative malformed inputs are covered.
