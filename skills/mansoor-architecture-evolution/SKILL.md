# Mansoor Architecture Evolution
Reverse-engineer the current boundaries, dependencies, data ownership and deployment shape before proposing a change. Prefer incremental seams and compatibility adapters over broad rewrites. State migration order, rollback, observability and ownership. Use Open-Source-First evidence for reusable architecture.

Stop condition: the smallest safe evolution path and rollback boundary are accepted by the manager.
