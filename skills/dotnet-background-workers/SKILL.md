# .NET Background Workers

Make workers cancellation-aware, bounded and observable. Create DI scopes for scoped services; do not capture scoped dependencies in singleton workers. Define idempotency, retry/backoff, poison-message handling and shutdown behavior. Avoid unbounded in-memory queues for durable work. Track correlation IDs and distinguish transient from permanent failures.
