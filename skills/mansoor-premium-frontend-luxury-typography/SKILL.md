# Mansoor Luxury Typography
Choose type by role, language coverage, licensing and rendering behavior. Build a fluid scale with readable measure, intentional tracking and robust fallbacks. Test long labels, localization, user zoom and font-loading failure; typography must not depend on animation to remain legible.

Stop condition: hierarchy, contrast, wrapping and fallback rendering pass the content stress cases.
