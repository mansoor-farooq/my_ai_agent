# Premium ebook publishing

Model the publication as semantic chapters, navigation, metadata, cover, accessible headings, captions, links, and reading-order structure. Decide reflowable versus fixed layout from the content and target readers; do not force a print layout into a reflowable book without testing.

Validate the package structure, embedded fonts/assets, media overlays if used, language metadata, table of contents, and representative reader sizes. Keep a reproducible source-to-EPUB/PDF build record.

Stop when the package opens in the target reader checks and no orphaned or unreadable content remains.
