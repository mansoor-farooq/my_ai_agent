# .NET Web UI Architecture

Match the product's rendering and interaction needs: MVC/Razor Pages for server-rendered workflows; Blazor when interactive .NET UI is justified. Keep UI state and presentation separate from business rules. Validate forms server-side, provide accessible labels and focus behavior, handle loading/empty/error states, and protect state-changing requests. Never expose server secrets to browser code.
