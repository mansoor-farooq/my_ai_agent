# Mansoor Interaction Physics
Use bounded spring/inertia models with explicit rest thresholds and input cancellation. Keep hit targets, keyboard equivalents and touch scrolling intact. Clamp pointer influence to the component boundary and avoid trapping the user in decorative motion.

Stop condition: interaction is reversible, interruptible, keyboard-accessible and stable on touch and mouse.
