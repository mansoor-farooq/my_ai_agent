# Learner calibration
Infer level from the conversation, state the target, and ask at most one high-value question when uncertainty changes the lesson. Respect Roman Urdu/English voice phrasing and never gate a simple answer behind a questionnaire.
Stop condition: level and target are explicit enough for the next explanation.
