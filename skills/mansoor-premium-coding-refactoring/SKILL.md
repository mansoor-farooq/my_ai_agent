# Premium refactoring

Capture current behavior first, make one structural move at a time, and run focused regression checks after each risky seam. Preserve IDs, API shapes, permissions, persistence semantics, and user-visible states unless explicitly changed.

Stop when the requested quality outcome is evidenced and no unrelated cleanup remains.
