# Mansoor Web Performance
Measure before changing. Capture repeatable route/device/network conditions, identify the dominant bottleneck, make one bounded change, and rerun the same measurement. Separate lab Lighthouse from field data and report both when available. Keep a regression budget for size, latency and interaction.

Stop condition: the bottleneck and before/after evidence are clear, or the measurement is unverified.
