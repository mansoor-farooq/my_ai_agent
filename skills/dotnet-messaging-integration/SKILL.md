# .NET Messaging & Integrations

Define message ownership, schema/version, delivery semantics, ordering and idempotency. Assume at-least-once delivery unless proven otherwise. Use an outbox/inbox when database state and message publication must stay consistent. Validate webhook signatures and replay windows. Apply timeouts, bounded retries and dead-letter handling; isolate external models behind adapters.
