# Local context compression

Keep the task contract, changed-path map, relevant symbols, current failures, acceptance checks, and provenance. Drop unrelated files and duplicate prose. Mark summaries as derived evidence and preserve paths/line references so the model can retrieve the source when needed.

Stop when the compressed packet fits the observed budget without removing a required invariant.
