# Premium Backend Query Performance
Measure representative workload before editing. Inspect query plans, cardinality, indexes, pagination, cache behavior and serialization cost; fix the dominant bottleneck without weakening tenant/security filters. Compare before/after latency and resource budgets under the same conditions.

Stop condition: the bottleneck and measurable regression budget are confirmed or the performance claim stays unverified.
