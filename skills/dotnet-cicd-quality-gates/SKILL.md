# .NET CI/CD Quality Gates

Create reproducible restore/build/test/publish steps pinned to supported SDKs. Cache packages safely, publish test results and fail on warnings only when repository policy requires it. Add format/analyzer/security checks incrementally. Separate build from deployment credentials, use environment approvals for production, and retain rollback artifacts.
