# Local task decomposition

Split by disjoint paths and contracts, not arbitrary token chunks. Give each packet objective, inputs, allowed tools, owned paths, acceptance checks, and stop condition. Serialize shared writes and let read-only research run in parallel only when evidence is independent.

Stop when the plan has no hidden overlap or unowned dependency.
