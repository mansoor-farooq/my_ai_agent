# Mansoor SEO Live Audit
Use the live-browser ladder when a URL is in scope: host browser, project tooling, isolated Chromium fallback. Inspect rendered page and served HTML separately, capture route/viewport/console/network evidence, then run Lighthouse last for successful scenarios. Rank findings by impact, affected pages and effort; never infer live behavior from static source alone.

Stop condition: browser evidence plus final Lighthouse result are recorded, or the URL/tool is explicitly blocked.
