# Local model evaluation

Record model/backend identity, prompt/config hash, repository revision, acceptance criteria, checks, latency, and review status. Separate draft observations from owner-approved benchmark evidence. Compare against the task baseline, not a vague “smartness” claim.

Stop when the evaluation is reproducible and limitations are visible.
