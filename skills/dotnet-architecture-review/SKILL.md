# .NET Architecture Review

Report observed facts, inferences and unknowns separately. Inspect solution/project files, references, entry points, persistence, tests, deployment and configuration. Trace representative features end to end. Classify findings by severity with evidence and remediation. Check dependency direction, layer leakage, duplicated rules, transaction ownership, tenant isolation and operational complexity. Recommend measurable fitness checks.
