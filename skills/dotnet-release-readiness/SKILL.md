# .NET Release Readiness

Verify supported runtime, configuration, auth, data migrations, health/readiness, logs/metrics, backup/restore, rate limits, resource limits, CI results and rollback plan. Exercise critical journeys and failure modes. Confirm no secrets or debug endpoints ship. Report blockers distinctly from accepted risks; tie readiness claims to evidence.
