# Premium coding contracts

Write objective, scope, owned paths, non-goals, acceptance criteria, dependencies, rollback notes, and verification commands before implementation. Split independent work only when ownership is disjoint; serialize overlapping edits.

Stop when the plan is concrete enough for an independent reviewer to detect scope drift.
