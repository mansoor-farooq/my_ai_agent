# Mansoor UI State Quality
Inspect real rendered states: loading, empty, error, content, long text, keyboard/focus, responsive constraints, theme contrast and 200% zoom where relevant. Reuse project tokens and primitives. Avoid fixed-height text clipping, hidden errors and behavior-changing visual rewrites.

Stop condition: rendered evidence covers the changed states and no known overflow or accessibility blocker remains.
