# Mansoor Mobile Release
Preserve navigation, state management, API IDs and platform permissions. Cover compact/large layouts, keyboard/safe areas, loading/empty/error/offline/permission states and semantics. Prefer static analysis plus focused widget/integration checks; require real-device evidence when the claim depends on hardware.

Stop condition: changed behavior and the device/tool limitation are explicit in the release handoff.
