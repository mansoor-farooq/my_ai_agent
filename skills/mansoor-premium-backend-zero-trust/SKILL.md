# Premium Backend Zero Trust
Authenticate every request and service hop, authorize the specific action and resource, bind identity to tenant and request context, and validate token lifetime, audience and revocation using the existing contract. Never trust an internal network location or client-supplied role.

Stop condition: allowed and rejected identities/actions are covered by executable tests and audit evidence.
