# Creative asset provenance

Create an asset ledger containing path, creator/provider, source URL or repository, license, modification status, generation prompt or model metadata when available, and allowed distribution scope. Separate approved local assets from inspiration and never silently copy a reference.

Flag missing or incompatible licenses before packaging. Keep a deterministic replacement path for any optional asset that cannot ship.

Stop when every shipped visual dependency is attributable or explicitly marked private-only.
