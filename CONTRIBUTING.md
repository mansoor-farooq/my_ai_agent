# Contributing to Ultra Agent

Ultra Agent is an owner-led Antigravity agent system. Contributions should preserve project identity, permission boundaries, evidence records and existing application contracts.

## Before you open a pull request

- Read the [quickstart](docs/quickstart.md) and [architecture](docs/architecture.md)
- Keep changes scoped to one problem and document the affected paths
- Add or update tests for behavior changes
- Run `npm test` and report any default-gated PostgreSQL RAG checks separately
- Run `npm run secret-scan`
- Never commit credentials, private keys, customer data, hidden reasoning or native Antigravity profile logs

## Pull request notes

Describe the user problem, the design choice, verification commands and any unverified environment-dependent checks. Do not claim public redistribution rights for bundled skills without a verified source and licence.
