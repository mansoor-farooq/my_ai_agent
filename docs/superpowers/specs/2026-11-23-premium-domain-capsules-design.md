# Premium Domain Capsules

## Intent

Move the Mansoor ecosystem from ordinary production routing to a premium, on-demand domain lane. Each domain exposes twelve custom skill slots and twelve bonus specialist roles. The manager activates only the roles required by the task, while the normal production, permission, WSL/Windows and isolated-worktree contracts remain unchanged.

## Domain contract

Twenty-one domains are registered: frontend, backend, database, security, architecture, coding, local model, creative production, document publishing, catalog commerce, SEO, web performance, Flutter/mobile, UI/UX, media/video, image generation, CI/release, data/ML, workflow automation, research/docs and agent-hub maintenance. Every domain has exactly twelve skill IDs and twelve role IDs. Skill slots may point to a locally-authored premium skill or a governed existing skill; every slot has an evidence requirement and stop condition.

## Premium local-model lane

The local-model capsule wraps an available Ollama, llama.cpp, vLLM or other injected backend with probing, project-scoped retrieval, compressed context, bounded decomposition, structured tool calls, independent verification, replayable memory, evaluation and resource-aware fallback. It improves effective task quality without claiming to change the model weights or silently switching providers.

## Premium architecture lane

The architecture capsule upgrades the existing SaaS/schema specialists with system mapping, domain boundaries, modular-versus-service tradeoffs, data contracts, event consistency, deployment topology, scalability, reliability, security architecture, ADRs, migration seams and independent verification. It is manager-routed before implementation for architecture-sensitive work and does not create a second manager.

## Premium coding lane

The coding capsule turns implementation into a governed loop: reconstruct the repository, approve an implementation contract, write focused regression tests, implement with type and boundary discipline, debug from evidence, measure performance, verify security/integrations, review independently and return release evidence. It keeps the manager as the only dispatcher and activates at most five bonus roles per wave.

## Premium frontend lane

The frontend capsule explicitly covers cinematic art direction, Three.js/WebGL, shader materials, scroll-driven storytelling, CSS motion, View Transitions, interaction physics, responsive composition, luxury typography, asset provenance, performance budgets and accessibility/visual regression. The visual stack is TypeScript/React/CSS/WebGL/Three.js when project evidence supports it; no custom programming language is invented merely for aesthetics.

## Premium backend lane

The backend/database capsule adds threat modeling, zero-trust authorization, tenant isolation, schema evolution, migration safety, idempotency/concurrency, observability, resilience, supply-chain controls, contract testing, query/performance hardening and release audit.

## Premium creative lane

Creative production adds custom art direction, campaign banners, generated imagery, layout systems, typography/color, provenance, print PDF, EPUB, catalog composition, UI/UX prototyping, export preflight and rendered visual QA. Document and catalog capsules reuse the same governed skills with format-specific gates for page rendering, reading order, data reconciliation and delivery matrices.

## Bonus roles

Bonus roles are manager-owned prompt capsules, not extra managers. They are dormant until routing selects them. At most five independent roles run in one wave; a premium polish role and an independent verifier form a barrier before promotion.

## Safety and compatibility

No provider credentials, unrestricted host permissions, automatic third-party copying or native Antigravity rewrite is introduced. Open-Source-First, Lighthouse final-gate, evidence states, provenance, Turbo permissions and isolated promotion remain mandatory.
