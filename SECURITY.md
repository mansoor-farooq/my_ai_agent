# Security policy

## Report a vulnerability

Please do not publish credentials, private project files or exploit details in a public issue. Use a private GitHub security advisory for this repository or contact [Mansoor Farooq](https://github.com/mansoor-farooq) privately with the affected version, reproduction steps and impact.

## Scope

Reports are welcome for the portable installer, managed MCP runtime, path and command guards, secret redaction, package integrity checks and project-memory boundaries.

The public repository does not contain provider keys, customer data, private chats or the owner signing key. Do not submit those materials in an issue or pull request.
